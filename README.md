# Mastigô — site

Site público do **Mastigô** (https://mastigô.com), sistema para nutricionistas que atendem crianças com seletividade alimentar.

Este repositório tem **só os arquivos do site** (a pasta `dist/` do projeto). O código-fonte completo, o servidor e os testes ficam no repositório privado `pipoca-pro`. Não edite aqui: altere no `pipoca-pro` e publique a pasta `dist/` de novo.

Versão de demonstração: os dados ficam no navegador de quem usa. Use só dados fictícios.
